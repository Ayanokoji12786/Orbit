## Release test expansion

Add focused unit tests for parsers and business rules, integration tests for Edge Functions and RLS in an isolated Supabase database, then two-account meeting/message/poll/storage tests. The PGlite deletion test simulates completed Storage removal by deleting test metadata; it cannot prove Storage byte deletion or the Auth Admin API. Install and test the Cron worker from [its runbook](ORBIT_ACCOUNT_DELETION_WORKER.md), including a 202 followed by app closure. Exercise fresh and expired sign-ins, interrupted deletion retries, a lost final deletion response, large file/room pagination, still-valid JWTs, denied permissions, offline/reconnect, failed uploads, duplicate actions and notification taps. Record iOS and Android results separately. Do not substitute web preview or mocked data for native verification.
